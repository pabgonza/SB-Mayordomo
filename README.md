# SB-Mayordomo

Páginas públicas de SB Mayordomo, la aplicación personal de escritorio que organiza
mi sistema de notas local a partir de mi propio correo.

Este repositorio existe para cumplir el requisito de Google Cloud de publicar una
página principal y una política de privacidad accesibles antes de sacar la app del
estado de prueba. El código de la aplicación no vive acá.

- `index.html` — qué es la aplicación y qué hace con Gmail.
- `privacy.html` — política de privacidad.

Servidas con GitHub Pages desde la rama `main`.
